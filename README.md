# Krutidev Typing Tutor

Kruti Dev 010 (Remington) Hindi typing seekhne ke liye free web app — Typing Master jaisa step-by-step course.

- **12 lessons**: Home / Top / Bottom / Number row (normal + Shift), matra & barakhadi, aadhe akshar, र ke roop, 100 common words, vakya
- **Live Hindi preview**: English (US) keyboard par type karein, screen par Kruti Dev jaisa Hindi output dikhega — font install ki zaroorat nahi
- **Virtual keyboard** agli key aur ungli highlight karta hai, galti par flash
- **5 speed tests** timer ke saath (gross / net WPM, accuracy, galat shabd)
- **Progress** browser (localStorage) me save hoti hai
- Saath me printable **PDF manual**

Plain HTML/CSS/JS — koi build step nahi. Local chalane ke liye:

```
python3 -m http.server 8000
```
